自动化测试工厂平台

自动化测试调度与环境管理平台，提供测试环境的全生命周期管理和测试任务的自动化调度执行。

## 项目架构

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────┐
│  测试管理服务  │────▶│  测试调度服务 :8002 │────▶│  Jenkins     │
│  (外部系统)   │     │  scheduler_service │     │  (构建执行)   │
└──────────────┘     └────────┬─────────┘     └──────────────┘
                              │ 申请/释放环境
                              ▼
                     ┌──────────────────┐
                     │  环境管理服务 :8001 │
                     │  env_service      │
                     └────────┬─────────┘
                              │
                     ┌────────▼─────────┐
                     │  PostgreSQL :5432 │
                     └──────────────────┘
```

### 核心服务

| 服务 | 端口 | 职责 |
|------|------|------|
| 环境管理服务 (env_service) | 8001 | 环境类型/物理环境/主机 CRUD、状态管理、健康检查 |
| 测试调度服务 (scheduler_service) | 8002 | 任务接收、动态/指定环境调度、Jenkins 集成、任务监控 |
| PostgreSQL | 5432 | 数据持久化 |

### 共享模块 (shared)

- **config.py** — 基于 pydantic-settings 的配置管理
- **database.py** — SQLAlchemy 异步数据库连接
- **models.py** — 9 个 ORM 数据模型 + 6 个枚举类型
- **schemas.py** — Pydantic 请求/响应数据模型

## 技术栈

- **Web 框架**：FastAPI + Jinja2 模板
- **数据库**：PostgreSQL 16 + SQLAlchemy 2.0 (async)
- **数据验证**：Pydantic v2
- **HTTP 客户端**：httpx
- **CI/CD**：Jenkins（支持 Mock 模式）
- **测试框架**：pytest（集成测试 + 压力测试）
- **容器化**：Docker + Docker Compose
